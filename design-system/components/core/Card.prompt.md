One-line: the container for everything — a soft white panel on the sky ground.

```jsx
<Card eyebrow="Booth 07" title="Study Abroad Exhibition" accent="var(--scrap-terracotta)" interactive>
  <p>Far corner · 20 points</p>
</Card>
```

`tone="green"` inverts for footers and hall screens. `accent` keys a card to a booth's colour;
it is the only place a paper-scrap colour touches chrome. Never add a border — the shadow does the work.
